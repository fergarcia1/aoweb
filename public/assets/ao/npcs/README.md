# NPCs neutrales

NPCs con los que se comercia o interactúa (sacerdote, herrero, banquero, etc.).

Por ahora los sprites reutilizan assets de `razes/` (caras) y `armors/` (cuerpo).
Esta carpeta queda reservada para assets exclusivos de NPCs en el futuro.

Definiciones en código: `src/npcs/npcDefinitions.ts`
