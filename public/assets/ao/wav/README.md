# Sonidos de hechizos (WAV)

Archivos `{índice}.wav` de Argentum / Imperium Clásico, enlazados por `game-data/spellCastMeta.ts` (`wav` por `idSpell`).

Copiar desde tu instalación de Imperium:

```bash
npm run wav:spells
```

Origen por defecto: `Imperium-Clasico/Fixtures/Recursos descomprimidos/Wav`.  
Variable opcional: `IMPERIUM_WAV_DIR`.
